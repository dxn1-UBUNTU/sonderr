# Integrations

{% partial file="sonderrclaw-eol.md" /%}

Configure integrations and settings for your SonderrClaw agent. Connect third-party services to give your agent access to repositories, issue trackers, calendars, documents, and hundreds of other tools — all without manual intervention.

## Available Integrations

- [**GitHub**](/docs/sonderrclaw/development-tools/github) — Clone repositories, push commits, open pull requests, and leave code reviews.
- [**Google Workspace**](/docs/sonderrclaw/development-tools/google) — Access Gmail, Calendar, Drive, Docs, Sheets, Slides, Tasks, and more.
- [**Linear**](/docs/sonderrclaw/development-tools/linear) — Create and update issues, read projects, and track work in Linear.
- [**Composio**](/docs/sonderrclaw/development-tools/composio) — Access 250+ tool integrations through a single connection.
- [**1Password**](/docs/sonderrclaw/tools/1password) — Securely manage credentials and let your agent fetch API keys or passwords without ever seeing them in plain text.
- [**Brave Search**](/docs/sonderrclaw/tools/brave-search) — Equip your agent with real-time web browsing via the Brave Search API.
- [**AgentCard**](/docs/sonderrclaw/tools/agentcard) — Enable your agent to perform financial transactions using virtual debit cards.
- [**Setting Up Other Tools**](/docs/sonderrclaw/tools/other-tools) — Configure your agent to use any third-party tool with a CLI or API.
