Search the web for current information, documentation, news, and recent data.

Use this tool when:
- You need information beyond your knowledge cutoff (today's date, recent events, latest versions)
- You're looking for documentation or API references for a library/framework
- You need to verify facts or find examples
- The user asks about current events, trends, or recent developments
- You're troubleshooting an error and need to find solutions

Search tips:
- Be specific: "React 19 useEffect cleanup behavior" beats "React hooks"
- Include version numbers when relevant: "Next.js 15 app router migration"
- Use the current year for recent information
- For documentation, include "docs" or "documentation" in the query
- For errors, include the exact error message in quotes

Search types:
- `auto` (default): balanced speed and comprehensiveness
- `fast`: quick results when you need a fast answer
- `deep`: comprehensive search for complex research

Live crawl modes:
- `fallback` (default): use live crawling if cached content unavailable
- `preferred`: always fetch fresh content (slower but more current)

When to use webfetch instead:
- You have a specific URL and want to read its content
- You need the full text of a documentation page or article
- Following up on a search result to get more detail

Rate limit awareness:
- Batch related searches when possible
- Use specific queries to avoid needing multiple searches
- Prefer local tools (grep, read) when the information is in the codebase
